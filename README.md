# Juego de Bart (Unity 6.3 LTS)

Mini nivel 2D con Bart Simpson. Compatible con Unity 6000.3.11f1 y 6000.3.29f1.

Hecho por **DanerCg**.

## Controles
- Flecha arriba: izquierda
- Espacio: derecha
- P: saltar

## Que incluye
- Movimiento y salto de Bart
- Bloques que suenan y se mueven al golpearlos desde abajo
- Zona de caida: sonido, animacion y reinicio automatico del nivel
- Marca de agua "DanerCg" abajo a la derecha

## Scripts (Assets/Scripts)
- PlayerController.cs
- BumpBlock.cs
- FallZone.cs
- WatermarkDanerCg.cs

## Requisitos
- Unity 6.3 LTS
- Paquete Input System (Window > Package Manager)
- Edit > Project Settings > Player > Active Input Handling: "Input System Package (New)" o "Both"
